# 令牌管理增强：长度提升 / 令牌级模型白名单 / 额度编辑

## Goal

令牌管理三项增强：

1. **令牌长度提升**：新生成的 API 令牌随机部分从 24 字节（约 32 字符）提升到 32 字节（43 字符，含 `sk-` 前缀总长约 46）。
2. **令牌级可用模型白名单**：每个令牌可独立限制可用模型（精确匹配），管理员与用户均可配置；与用户级 `users.allowed_models` 同时存在时**取交集**生效。
3. **已创建令牌的额度编辑**：管理台提供编辑入口，可修改额度总额（含清回无限）与已用额度（含清零）。

## Background（用户已确认的决策）

- 随机部分长度：32 字节。
- 白名单配置方：**管理员 + 用户**（用户仅能配置/收窄自己令牌的白名单，不可触碰额度）。
- 白名单放行语义：令牌级与用户级白名单**取交集**（两条清单各自允许才放行）。

## Requirements

### R1 令牌长度

- 管理台与用户端新建令牌均使用 32 字节随机部分。
- **仅对新生成令牌生效**；存量令牌按 `key_hash` 校验，不受影响。
- 会话 token、渠道 ID、OAuth state、随机密码等其他 `generateToken` 用途的输出长度**不得变化**。

### R2 令牌级模型白名单

- `tokens` 表新增 `allowed_models` 列（JSON 数组字符串；NULL / 空 = 不限制），需编号迁移 + `schema.sql` 同步。
- 生效点（与用户级白名单同语义：精确匹配、大小写敏感、匹配对象为别名解析前的原始 `body.model`）：
  - `/v1/chat/completions` 等 OpenAI 代理路径：白名单外模型 403 `model_not_allowed`。
  - `/anthropic/v1/messages`：同上。
  - `/v1/models`：返回列表同时受令牌级与用户级白名单过滤。
- 管理台：创建模态与编辑模态均可配置白名单（候选 = 全部模型）；列表需展示每个令牌的限制状态（全部 / N 个模型）。
- 用户端：创建模态与编辑模态均可配置白名单（候选 = 用户自己可见模型）；列表同样展示限制状态。
- 用户端不可配置任何额度字段（quota_total / quota_used 仅管理员可改）。

### R3 额度编辑（管理台）

- 令牌列表每行新增「编辑」入口，模态内可修改：名称、额度总额（`quota_total`，可清回无限）、已用额度（`quota_used`，可清零）、模型白名单。
- 后端 `PATCH /api/tokens/:id` 修正三态语义：`undefined` = 保留旧值、`null` = 清除（额度清回无限）、具体值 = 设置。（现状 bug：`quota_total` 传 `null` 会回退旧值，无法清回无限。）
- 非法数值（负数 / 非数字）返回 400，不再静默回退旧值。

## Out of Scope

- 令牌级 `allowed_channels` 的 UI 编辑（其 per-model map 存量格式复杂且未在本次需求内；后端三态修正顺带覆盖，但 UI 不做）。
- 用户端额度自助调整（涉及计费策略，明确排除）。
- `/api/models`（模型广场）、`/api/public`（公开模型）不受令牌白名单影响。
- 存量令牌的长度迁移 / 强制轮换。

## Acceptance Criteria

- [ ] AC1 新建令牌明文长度为 46（`sk-` + 43 字符 base64url）；管理员会话、用户会话、渠道 ID、OAuth state 长度与现状一致。
- [ ] AC2 存量令牌（迁移前创建）无需任何处理即可继续通过 `/v1/*`、`/anthropic/v1/*` 调用。
- [ ] AC3 管理员为令牌配置白名单后：白名单外模型请求返回 403 `model_not_allowed`；`/v1/models` 不再返回白名单外模型名。
- [ ] AC4 令牌级与用户级白名单同时存在时，模型须同时被两清单允许才放行（任一清单排除即 403）。
- [ ] AC5 用户可在用户端为自己令牌配置/修改白名单；用户端任何接口无法修改 quota 字段（服务端拒绝或忽略）。
- [ ] AC6 管理台编辑模态可将 `quota_total` 清回无限（NULL）、将 `quota_used` 清零，保存后列表即时反映。
- [ ] AC7 迁移文件 `0020_*.sql` 可对存量库重放（幂等追加列）；`schema.sql` 与迁移一致；全新初始化路径（init 工作流）行为正确。
- [ ] AC8 白名单交集语义、令牌长度、PATCH 三态解析均有单测覆盖（沿用 `tests/` 纯函数测试模式）。
- [ ] AC9 `bun run check && bun run typecheck && bun run test` 全绿。
